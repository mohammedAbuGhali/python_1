# Python 1 — Learning Repository

A starter repository for my Python programming practice. Use it to collect exercises, small experiments, and beginner projects as I learn the language.

## Getting started

1. Install Python 3 from [python.org](https://www.python.org/downloads/).
2. Clone this repository:

   ```bash
   git clone https://github.com/mohammedAbuGhali/python_1.git
   cd python_1
   ```

3. Create a Python file for an exercise, for example `hello.py`, and run it:

   ```bash
   python hello.py
   ```

   Depending on your setup, the command may be `python3 hello.py`.

## Suggested organization

As the repository grows, consider grouping related work into folders, for example:

```text
.
├── basics/
├── exercises/
└── mini-projects/
```

There are no third-party dependencies or application-specific run commands documented yet; add those here when a project requires them.

## Learning goals

- Practice Python syntax and core concepts.
- Build confidence by solving exercises and creating small projects.
- Keep examples easy to run and understand.
